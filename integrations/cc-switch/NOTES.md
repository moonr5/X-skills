# CC Switch

Official site named by the repository: https://ccswitch.io

This is a Tauri desktop utility, not a skill collection. The tree has no `SKILL.md`. It was cataloged as a non-skill resource.

The README describes it as a manager for Claude Code, Claude Desktop, Codex, Gemini CLI, Grok Build, OpenCode, OpenClaw, Hermes Agent, Pi, and MiniMax Code. It switches API providers and edits MCP, skill, and prompt configuration.

Nothing from this repository was installed. No provider, model, credential, or agent configuration was changed. Installing it requires a separate approval because it writes those configuration files.

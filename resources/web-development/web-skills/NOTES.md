This repository is a visual learning map for web-development topics. The tree contains a website (`index.html`, `package.json`, Firebase config) and a generated topic list in `README.md` and `blueprint.md`. It does not contain `SKILL.md` or another supported skill manifest.

It was cataloged as a non-skill resource. The topic pages were not converted into agent skills, and the website was not copied because the repository is about 120 MB and this disk has almost no free space.

Use the upstream site or README when a task needs that topic map. Do not treat a topic name from the map as an installed skill.

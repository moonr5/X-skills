The repository is an Astro site plus a skill registry. Only the `skills/` packages were imported. The website, npm package, and remote MCP endpoint at `https://www.ui-skills.com/mcp` were not installed or contacted.

`ui-skills-root` tells an agent to select skills through `npx ui-skills`. That CLI was not installed. The imported instruction files can be read without it.

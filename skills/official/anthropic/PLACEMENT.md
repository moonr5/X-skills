# Anthropic skills

Source: https://github.com/anthropics/skills
Commit: `dbd4588f9e1033efb41dad4bef2f7947c8993d44`

This folder is the requested destination. The skill files themselves stay in the catalog paths below so the same package is not stored twice. Search finds them by name.

Open-source example skills use the Apache-2.0 text in each skill's `LICENSE.txt`. The document skills `docx`, `pdf`, `pptx`, and `xlsx` are source-available and their license forbids retaining copies outside Anthropic services. Those four are recorded as source links only.

`spec/` is the Agent Skills specification, not an installable skill. `template/` is the skill template and is cataloged as `template-skill`.
